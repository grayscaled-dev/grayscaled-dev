# Hi, I'm Louis

Director of [Grayscaled](https://grayscaled.dev) and builder of [EasyKSB](https://easyksb.com). 

I build infrastructure, web apps, and developer tooling. Most of my work lives in private repos, but here's what I'm working with.

## What I do

- **Grayscaled** - Software consultancy for startups and SMEs. Web apps, cloud infrastructure, DevOps.
- **EasyKSB** - KSB tracking tool for UK apprentices. Matches evidence to Knowledge, Skills and Behaviours for End-Point Assessment.
- **BAE Systems** - Cyber Security at BAE Systems Digital Intelligence.
